# netgaming20-max.github.io

`mediaplayer/` is the player page used by the FiveM **mediaplayer** resource. YouTube's embedded player only plays
on a page served from a real https website, so the in-game player loads it from here.

The source of truth is `mediaplayer/html/dui.html` and `dui.js` in the server repo. Copy them here when they change.
